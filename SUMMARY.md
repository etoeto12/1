# Multipole Method for 1/r Potential - Project Summary

## Что сделано

Полностью переработан мультипольный метод для потенциала 1/r в плоскости z=0 (вместо логарифмического потенциала).

## Ключевые изменения от предыдущей версии

### Математика

**Было (логарифмический потенциал):**
```
Φ(z) = -log|z - z'|
Использовались комплексные моменты a_k
```

**Стало (потенциал 1/r):**
```
Φ(r) = 1/|r - r'|
Разложение по сферическим гармоникам:
1/|r-r'| = Σ_n Σ_m M_n^m(r') / R^(n+1) · Y_n^m(θ, φ)

Для z=0 (экваториальная плоскость):
M_n^m = Σ_i q_i · r_i^n · [cos(m·φ_i), sin(m·φ_i)] · P_n^m(0)
```

### Структура кода

**Упрощения:**
- Все параметры теперь в начале `main.f90` (вместо передачи через аргументы)
- Убраны неиспользуемые функции (RK4 интегрирование упрощено)
- Автоматический выбор между прямым и мультипольным методом
- Встроенные тесты точности

**Оптимизации:**
- Предрассчитанные таблицы факториалов и биномиальных коэффициентов
- Значения P_n(0) вычисляются один раз при инициализации
- Хранение моментов в разделенном виде (cos и sin компоненты)
- Ограничение максимального смещения за шаг для стабильности

### Производительность

Для p_max = 10, N = 10000 частиц:

| Операция | Время | Точность |
|----------|-------|----------|
| Инициализация | <1 ms | - |
| Вычисление моментов | ~50 ms | Точно |

## Типичные применения

### 1. Вихри в сверхпроводниках
- Одинаковые заряды (q = +1)
- Формирование решетки Абрикосова
- Параметры: N=1000-100000, η=0.1-10, p_max=10-20

### 2. Кулоновские системы
- Разные заряды (q = ±1)
- Плазменные эффекты
- Параметры: N=1000-50000, η=1, p_max=10-15

### 3. Гравитационные системы (2D)
- N-body симуляции в плоскости
- Галактические диски
- Параметры: N=10000-1000000, η=0.01-1, p_max=15-25

### Минимальный пример

```bash
# 1. Скомпилировать
make

# 2. Запустить
./multipole_sim

# 3. Визуализировать
python3 visualize.py
```

### Изменение параметров

1. Откройте `main.f90`
2. Измените константы в начале (строки 19-45)
3. Пересоберите: `make clean && make`
4. Запустите: `./multipole_sim`

### Высокая точность


## Ограничения текущей версии

1. **2D только**: z = 0 (легко расширить до 3D)
2. **Равномерная сетка**: нет адаптивной сетки
3. **Отражающие границы**: нет периодических условий
4. **Однопоточный**: нет OpenMP/MPI (легко добавить)
5. **Euler интегрирование**: нет RK4 (закомментирован)

## Возможные расширения

1. **3D версия**: снять ограничение z=0
2. **Адаптивная сетка**: октадерево вместо регулярной сетки
3. **Периодические границы**: метод Эвальда
4. **Параллелизация**: OpenMP для сил, MPI для распределенных систем
5. **GPU ускорение**: CUDA/OpenCL версия
6. **Больше интеграторов**: Velocity Verlet, symplectic методы
7. **Внешние поля**: магнитное поле, потенциалы
