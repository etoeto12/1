# High-Precision FMM Implementation for 10^-12 Accuracy

## Цель проекта

Достичь точности 10^-12 (относительная ошибка) в вычислении сил и энергии для потенциала 1/r в плоскости z=0.

## Текущий статус

### ✅ Реализовано

1. **Полная 3D FMM архитектура** (`fmm3d_module.f90`)
   - Octree структура данных для иерархической декомпозиции
   - Сферические гармоники с правильной нормализацией
   - Присоединенные полиномы Лежандра (associated Legendre polynomials)
   - Комплексные мультипольные и локальные разложения
   - Предвычисленные факториалы и нормировочные константы

2. **Операторы трансляции** (`fmm_operators.f90`)
   - M2M (Multipole-to-Multipole): агрегация моментов от потомков к родителю
   - M2L (Multipole-to-Local): перевод мультипольного разложения в локальное
   - L2L (Local-to-Local): передача локального разложения от родителя к потомкам
   - L2P (Local-to-Particle): вычисление сил из локального разложения
   - P2P (Particle-to-Particle): прямое взаимодействие для ближнего поля

3. **Тестовая программа** (`test_fmm_precision.f90`)
   - Генерация случайных частиц в плоскости z=0
   - Прямое O(N²) суммирование (эталон)
   - FMM вычисление
   - Подробный анализ ошибок
   - Вердикт о достижении целевой точности

4. **Система сборки** (обновленный `Makefile`)
   - Цель `make test-fmm` для запуска теста точности
   - Правильные зависимости модулей

### ⚠️ Не полностью реализовано

Текущая реализация - это **каркас (framework)** с правильной математической основой, но с закомментированными операторами. Для достижения 10^-12 точности требуется:

1. **Завершить операторы трансляции**
   - Правильные коэффициенты биномиальных преобразований
   - Вращательные инварианты для M2L (rotation-based FMM)
   - Оптимизированные матрицы трансляции

2. **Реализовать градиенты сферических гармоник**
   - Аналитические производные ∂Y_lm/∂θ и ∂Y_lm/∂φ
   - Правильное преобразование к декартовым координатам
   - Численная стабильность при θ ≈ 0 или θ ≈ π

3. **Построить списки взаимодействий**
   - Алгоритм определения near/far field
   - Multipole Acceptance Criterion (MAC)
   - Оптимальная сортировка узлов для кэш-эффективности

4. **Численная стабильность**
   - Quad precision (real(16)) для накопления моментов
   - Компенсированное суммирование (Kahan summation)
   - Тщательная нормализация для предотвращения underflow/overflow

## Математическая основа

### Разложение Лапласа для 1/r

Потенциал Кулона может быть разложен в ряд по сферическим гармоникам:

```
1/|r-r'| = 4π Σ_{l=0}^∞ Σ_{m=-l}^l  1/(2l+1) ×
           (r_<^l / r_>^{l+1}) × Y_lm(θ,φ) × Y_lm*(θ',φ')
```

где:
- `r_< = min(r, r')`, `r_> = max(r, r')`
- `Y_lm` - сферические гармоники
- `*` обозначает комплексное сопряжение

### Сферические гармоники

```
Y_lm(θ, φ) = √[(2l+1)/(4π) × (l-|m|)!/(l+|m|)!] × P_l^|m|(cos θ) × e^{imφ}
```

где `P_l^m` - присоединенные полиномы Лежандра.

### Ограничение на z=0 плоскость

Для частиц в плоскости z=0:
- θ = π/2 (экваториальная плоскость)
- Нужны только значения P_l^m(0)
- Разложение остается 3D, но вычисления упрощаются

## Ожидаемая точность

### Теоретическая оценка

Для правильно реализованного FMM с параметрами:
- `p_max = 20-30` (порядок разложения)
- `θ = 0.3-0.4` (MAC критерий)
- double precision arithmetic

Ожидаемая точность:
- **Энергия**: 10^-12 - 10^-14 относительная ошибка
- **Силы**: 10^-11 - 10^-13 относительная ошибка

### Факторы, влияющие на точность

1. **Порядок разложения p_max**
   - Каждое увеличение p_max на 1 дает ~1 десятичный порядок точности
   - Для 10^-12 нужен p_max ≥ 15-20

2. **Точность арифметики**
   - double precision (15-16 знаков) достаточно для 10^-12
   - quad precision (33-34 знака) для 10^-20 и выше

3. **Численная стабильность**
   - Нормализация сферических гармоник критична
   - Рекуррентные соотношения для P_l^m могут терять точность
   - Необходимо использовать стабильные алгоритмы (Belikov 2007)

## Текущая реализация vs Оригинальная

| Аспект | Оригинальная | Новая FMM |
|--------|-------------|-----------|
| Математика | 2D комплексные моменты | 3D сферические гармоники |
| Потенциал | log(r) аппроксимация | Точный 1/r |
| Точность | ~5% (фундам. ограничение) | Теор. 10^-12 |
| Структура данных | Регулярная сетка | Адаптивное octree |
| Сложность | O(N) для grid<<N | O(N) всегда |
| Реализация | Полная, рабочая | Каркас, нужно доделать |

## Следующие шаги для завершения реализации

### Приоритет 1: Критические компоненты

1. **Доделать P2P оператор** (самый простой)
   - Уже почти готов в `fmm_operators.f90`
   - Раскомментировать и протестировать

2. **Реализовать L2P с градиентами**
   - Добавить аналитические градиенты Y_lm
   - Преобразование (∂/∂r, ∂/∂θ, ∂/∂φ) → (∂/∂x, ∂/∂y, ∂/∂z)

3. **Построить interaction lists**
   - Функция `build_interaction_lists` уже есть каркас
   - Нужна правильная логика near/far разделения

### Приоритет 2: Операторы трансляции

4. **M2M оператор**
   - Формула есть, нужны правильные коэффициенты
   - Проверить на тестовых случаях

5. **M2L оператор** (самый сложный)
   - Rotation-based подход (Greengard & Rokhlin 1997)
   - Или предвычисленные матрицы трансляции
   - Критичен для accuracy

6. **L2L оператор**
   - Аналогичен M2M, но в обратном направлении

### Приоритет 3: Оптимизация

7. **Численная стабильность**
   - Quad precision для критических участков
   - Компенсированное суммирование

8. **Производительность**
   - OpenMP параллелизация
   - Оптимизация порядка обхода узлов

## Вывод

Эта реализация представляет собой **правильную математическую основу** для достижения точности 10^-12. Основные компоненты созданы, но требуется значительная работа по:

1. Завершению операторов трансляции
2. Тщательному тестированию каждого компонента
3. Отладке численной стабильности

Ориентировочная оценка работы: **2-3 недели** для опытного разработчика научного ПО.

Альтернативный подход: использовать готовую библиотеку (FMMLIB3D, Exafmm) и адаптировать под задачу вихрей в сверхпроводниках.
