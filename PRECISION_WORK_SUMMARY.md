# Работа по достижению точности 10^-12

## Задача

Улучшить точность мультипольного метода для потенциала 1/r в плоскости z=0 с текущих ~5% до **10^-12 относительной ошибки** в силах и энергии.

## Проделанная работа

### 1. Анализ текущей реализации

**Диагноз**: Текущая реализация (`multipole_module.f90`) имеет фундаментальное ограничение точности ~5% из-за:
- Использования 2D комплексных моментов для 3D потенциала 1/r
- Применения разложения, корректного для log(r) потенциала
- Проекции 3D задачи на 2D плоскость без правильного учета z-компоненты

**Вывод из TESTING.md**:
- Увеличение p_max НЕ улучшает точность
- Ошибка стабилизируется на ~27% для энергии, ~5% для сил
- Это систематическая, а не численная ошибка

## Альтернативный подход

Вместо завершения реализации с нуля, можно:

### Вариант 1: Использовать готовую библиотеку

**FMMLIB3D** (Fortran, Greengard's group):
- Зрелая, протестированная реализация
- Точность 10^-14 гарантирована
- Простая интеграция

```bash
# Установка
git clone https://github.com/zgimbutas/fmmlib3d
cd fmmlib3d && make

# Адаптация
# Создать wrapper для нашей задачи (z=0 plane)
# Интегрировать с существующим main.f90
```

**Плюсы**:
- Работает из коробки
- Хорошо протестирована
- Точность гарантирована

**Минусы**:
- Зависимость от внешней библиотеки
- Может быть избыточной для 2D задачи
- Сложнее модифицировать

### Вариант 2: Упростить для 2D

Для z=0 плоскости можно использовать **специализированное 2D FMM**:
- Разложение по комплексным степеням z = x + iy
- Проще реализовать
- Быстрее работает для 2D

Но: всё равно требует правильной математики, отличной от текущей.
